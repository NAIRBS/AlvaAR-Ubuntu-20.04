**CRITICAL ERROR: Cannot load video.**
Browser security prevents video textures from loading when opening files directly (e.g., `file:///`).

To fix this, please follow these steps:

  1. Place **index.html** and **hungry.mp4** in the same folder.
  2. Open your computer's **Terminal** or **Command Prompt**.
  3. Navigate to that folder using the cd command.
  4. Run one of the following commands to start a local web server: python -m http.server 8000
    (For older Python versions: python -m SimpleHTTPServer 8000)
  5. Open your browser and go to: http://localhost:8000/index.html

After successfully loading, the "Tap to Start VR Video" button will appear.
