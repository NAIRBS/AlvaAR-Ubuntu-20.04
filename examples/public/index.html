AlvaAR

Real-time Visual SLAM for Web Browsers

Technology Overview

  • SLAM Engine: Modified OV²SLAM with ORB-SLAM2 features
  • Platform: WebAssembly (WASM) for browser compatibility
  • Visualization: Three.js for 3D AR rendering
  • Input Sources: WebSocket streams, video files, web cameras
  • Pose Format: 16-element 4x4 transformation matrices
